┌────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                             │
└────────────────────────────────────────────────────────────────┘

PROBLEM: "Supabase not initialized"
→ SOLUSI: Cek URL & key sudah benar di supabase-config.js

PROBLEM: "Failed to fetch"
→ SOLUSI: Cek internet connection & project status

PROBLEM: Soal tidak muncul
→ SOLUSI: Run ulang supabase-insert-questions.sql

PROBLEM: "Permission denied"
→ SOLUSI: Cek RLS policies di Supabase dashboard

PROBLEM: Session tidak tersimpan
→ SOLUSI: Verify function start_exam_session works
